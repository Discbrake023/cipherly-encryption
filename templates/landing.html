Fitur & Kemampuan

Fitur Kriptografi Terintegrasi

Implementasi standar industri dengan evaluasi performa dan integritas data.

Authenticated Encryption (AEAD)
Menggunakan AES-256-GCM dan ChaCha20-Poly1305. Menjamin kerahasiaan (*confidentiality*) sekaligus integritas (*tamper-proofing*) data dalam satu langkah.
Memory-Hard KDF Protection
Proteksi kata sandi dari serangan GPU/ASIC cracking menggunakan Argon2id, scrypt, dan PBKDF2-HMAC-SHA256 dengan 600.000 iterasi.
Zero-Knowledge File Vault
Enkripsi dan dekripsi berkas biner apa pun (PDF, gambar, dokumen) langsung ke format terproteksi .krp tanpa penyimpanan permanen di server.
Enkripsi Hibrida RSA-OAEP
Kombinasi efisiensi simetris (AES-GCM) dengan kemudahan asimetris (RSA-2048) untuk pertukaran pesan aman antar dua pihak.
Avalanche Effect & Shannon Entropy
Pengujian langsung keacakan bit: memastikan perubahan 1 bit plaintext/kunci mengubah ≈ 50% ciphertext dan menghasilkan entropi mendekati 8.0 bit/byte.
Pengujian Skenario UTS Otomatis
Pipeline otomatis untuk verifikasi 5 tahapan spesifikasi teknis termasuk deteksi kata sandi salah dan modifikasi ciphertext (tampering).
Standar Keamanan

Format Binary Envelope (CKV1)

Struktur byte deterministik yang menjamin interoperabilitas dan keamanan data.

Offset Panjang Field Deskripsi
0x00 - 0x03 4 Bytes MAGIC Magic identifier CKV1
0x04 1 Byte ALGO_ID 0x01 (AES-256-GCM) / 0x02 (ChaCha20-Poly1305)
0x05 1 Byte KDF_ID 0x01 (PBKDF2) / 0x02 (scrypt) / 0x03 (Argon2id)
0x06 - 0x15 16 Bytes SALT Garam acak kriptografis (CSPRNG)
0x16 - 0x21 12 Bytes NONCE / IV Initialization Vector unik per enkripsi
0x22 - 0x31 16 Bytes AUTH TAG Tag integritas AEAD (GCM / Poly1305)
0x32 - End Variabel PAYLOAD Ciphertext biner hasil enkripsi
